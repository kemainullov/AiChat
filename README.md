# AI Chat - Что на ужин? 🍽️

Android приложение для подбора идеального блюда на ужин с помощью DeepSeek AI.

## Настройка

Ключ DeepSeek API поместить в `local.properties`:
```
DEEPSEEK_API_KEY=ваш_ключ
```

## Описание

Приложение работает как **личный шеф-повар**:
- AI помогает подобрать блюдо на ужин
- Задает вопросы о предпочтениях (кухня, аллергии, время приготовления и т.д.)
- Автоматически останавливается после сбора информации
- Выдает рекомендацию с полным рецептом

## Использование

1. Запустите приложение
2. Ответьте на вопросы AI о ваших предпочтениях
3. Получите рекомендацию блюда с маркером "🍽️ РЕКОМЕНДАЦИЯ БЛЮДА"
4. Готовьте и наслаждайтесь!
